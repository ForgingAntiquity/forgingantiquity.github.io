# Forging antiquity site

The website for the research project "Forging Antiquity: Authenticity, forgery and fake papyri", based at Macquarie University, Sydney.

Funding for this project has been provided by the Australian Research Council, and Macquarie University in partnership with the University of Heidelberg.

This repo serves as the basis for the [project website](https://www.forgingantiquity.com), where there is information about the project, its goals, team, publications, and events, as well as the working list of forged papyri. 

This repository and associated project website was started with the assistance of Brian Ballsun-Stanton, has had many contributors since 2017, and is maintained by Malcolm Choat. The code in sections of some files, including html tables and some lists (in markdown), were produced with the assistance of Claude Sonnet 4.6.
